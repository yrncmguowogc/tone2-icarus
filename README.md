## Overview

Icarus combines wavetable morphing, additive re-synthesis, and spectral manipulation into a unified synthesis engine, enabling smooth transitions between timbres and unique animated soundscapes.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Tone2 Icarus** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Hyperwave Morphing** | Morph between up to 8 wavetables simultaneously with crossfade |
| **Spectral Engine** | Additive re-synthesis from imported samples for timbral editing |
| **Phase Distortion** | Per-partial phase manipulation creates complex waveform shapes |
| **Animation Sequencer** | Automate wavetable position with a dedicated LFO lane sequencer |
